# CPA Manager Plus v7.2.151-max.2

> Fork prerelease based on v1.12.10

> [English ->](https://github.com/2ue/CPA-Manager-Plus/blob/v7.2.151-max.2/docs/release-notes/v7.2.151-max.2-en.md)

## Overview

v7.2.151-max.2 将当前 fork 的主线状态重新封装为一个 `max` 预发布版本，延续 v1.12.10 里已经落地的凭证管理、额度展示和 Codex 旧身份验证改进。

## Highlights

### Features

- Credential Management 保留 `Enabled` 状态筛选，并继续把它和需要健康与额度证据的 `Available` 明确区分开。
- 不同凭证的额度刷新仍然可以并行执行，同一凭证的重复刷新会继续去重。

### Fixes

- 凭证操作通知继续显示在 Drawer / Modal 之上，刷新反馈也保留具体的 Provider 错误。
- Accounts 仍按语义分组标准、模型和其他额度窗口，避免误把 Billing / PAYG 当作标准区间额度。
- 从 snapshot 恢复的未知类型区间额度保持与实时数据一致的语义。
- xAI 周额度在上游未提供 `creditUsagePercent` 时继续保持“未知”。
- 大型 Codex 历史库的旧身份验证继续使用紧凑的派生 identity evidence。

## Upgrade Notes

- 这是一个标记为 `v7.2.151-max.2` 的 fork 预发布版本。
- 它保留当前主线行为，不需要手工迁移。
