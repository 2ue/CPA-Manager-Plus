# CPA Manager Plus v7.2.151-max.4

> Fork prerelease based on v1.12.12

> [English ->](https://github.com/2ue/CPA-Manager-Plus/blob/v7.2.151-max.4/docs/release-notes/v7.2.151-max.4-en.md)

## Overview

v7.2.151-max.4 将上游 v1.12.12 合入 fork 主线，同时保留二开特性。本次还修复了发布工具链：上游新引入的更新通道契约在结构上无法接受 `-max.N` 标签，现已正式支持。

## Highlights

### Features

- 凭证列表支持卡片视图，额度窗口在移动端与笔记本屏幕上自适应排布。
- 新增 Manager 更新检查与通知页面，发布后自动发布已验证的更新通道。
- 支持行内编辑优先级与备注，失焦自动保存；批量额度刷新受速率限制保护。
- Codex 重置卡额度徽章可直接跳转到详情锚点。

### Fixes

- 严格采用 Fail-Closed 处理重置卡结果，仅在明确成功时才同步网关冷却状态。
- xAI 未确认的额度不再展示，付费套餐判定改为严格门槛。
- 详情抽屉切换标签时不再丢失列表额度用量与预测。
- 面板外部更新检查可抵御过期响应竞态。

### Release Tooling

- 更新通道契约新增 `max` 阶段，`v7.2.151-max.4` 这类标签不再因 `Invalid release identity` 失败。
- `max` 是一条封闭发布线：fork 构建不会进入 stable / rc / beta 通道，上游 stable 也不会被当作 max 安装的更新推送。
- 仓库与镜像标识不再硬编码上游，改由 `GITHUB_REPOSITORY` / `CPAMP_REPOSITORY_SLUG` 解析，未设置时行为与上游完全一致。

## Upgrade Notes

- 这是一个标记为 `v7.2.151-max.4` 的 fork 预发布版本，无需手动迁移。
- 面板 `management.html` 现在由构建产出，不再提交到仓库；自定义部署可用 `PANEL_PATH` 指定。
