# CPA Manager Plus v1.12.8-max.1

> Fork prerelease based on v1.12.8

> [English ->](https://github.com/2ue/CPA-Manager-Plus/blob/v1.12.8-max.1/docs/release-notes/v1.12.8-max.1-en.md)

## Overview

v1.12.8-max.1 是面向当前 fork 的首个 `max` 预发布版本，重点补齐了账号级并发和 RPM 控制、缓存终值控制，以及请求监控里更完整的用量可视化。它继续沿用现有的账号管理和调度框架，但把常用控制项收拢到更接近账号和配置的地方，便于直接操作和批量治理。

## Highlights

### Features

- 账号详情页现在可以按单个凭证设置并发和 RPM，也可以在账号列表里批量下发同类限制。
- 缓存控制现在可以分别作用于读取、写入、输入和输出，支持阈值裁剪、倍率放大和抖动区间。
- 请求监控的用量展示更细，输入、输出和缓存维度现在更容易直接对照查看。

### Fixes

- Claude 相关的配置项和账号操作入口做了整理，常用控制不再分散在多个重复位置。
- 释放和发布链路修正为适配 fork 仓库的 `max` 标签与发布内容校验。

## Upgrade Notes

- 这是一个 fork 预发布版本，标签使用 `v1.12.8-max.1`。
- 现有账号数据和历史监控数据保持不变；新的并发、RPM 与缓存控制只影响后续请求。
