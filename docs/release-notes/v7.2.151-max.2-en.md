# CPA Manager Plus v7.2.151-max.2

> Fork prerelease based on v1.12.10

> [中文 ->](https://github.com/2ue/CPA-Manager-Plus/blob/v7.2.151-max.2/docs/release-notes/v7.2.151-max.2-zh.md)

## Overview

v7.2.151-max.2 repackages the current fork baseline as a `max` prerelease and carries forward the credential, quota, and legacy Codex identity improvements already present in v1.12.10.

## Highlights

### Features

- Credential Management keeps the `Enabled` status filter and continues to distinguish it from `Available`, which still depends on health and quota evidence.
- Quota refreshes for different credentials can still run concurrently, while repeated refreshes for the same credential remain deduplicated.

### Fixes

- Credential operation notifications stay above Drawer / Modal overlays, and refresh feedback continues to preserve exact provider errors.
- Accounts still group standard, model-scoped, and other quota windows by semantic meaning instead of mixing billing or PAYG windows into standard interval quota.
- Unknown-kind interval quota restored from snapshots keeps the same semantics as live data.
- xAI weekly usage remains unknown when upstream omits `creditUsagePercent`.
- Legacy Codex identity validation continues to use compact derived identity evidence for large histories.

## Upgrade Notes

- This is a fork prerelease tagged `v7.2.151-max.2`.
- It preserves current main-branch behavior and does not require manual migration.
