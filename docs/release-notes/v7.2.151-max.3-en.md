## Overview

v7.2.151-max.3 repackages the current fork baseline so this mirror image can be published cleanly.

## Highlights

### Features

- Credential Management continues to keep the current account-state filters and quota display behavior.
- Quota refreshes for different credentials can still run in parallel, while repeated refreshes for the same credential remain deduplicated.

### Fixes

- Credential operation notifications stay above Drawer / Modal overlays, and refresh feedback continues to preserve exact provider errors.
- Accounts still group standard, model-scoped, and other quota windows by semantic meaning instead of mixing billing or PAYG windows into standard interval quota.
- xAI weekly usage remains unknown when upstream omits `creditUsagePercent`.
- Legacy Codex identity validation continues to use compact derived identity evidence for large histories.

## Upgrade Notes

- It exists to publish the current fork image and does not require manual migration.
