# CPA Manager Plus v7.2.151-max.3

> Fork prerelease based on v1.12.10

> [English ->](https://github.com/2ue/CPA-Manager-Plus/blob/v7.2.151-max.3/docs/release-notes/v7.2.151-max.3-en.md)

## Overview

v7.2.151-max.3 重新封装当前 fork 主线状态，用于发布这次自己的镜像。

## Highlights

### Features

- Credential Management 继续保留当前账号状态筛选和额度展示行为。
- 不同凭证的额度刷新仍支持并行执行，同一凭证的重复刷新继续去重。

### Fixes

- 凭证操作通知继续显示在 Drawer / Modal 之上，刷新反馈也继续保留具体 Provider 错误。
- Accounts 仍按语义分组标准、模型和其他额度窗口，避免 Billing / PAYG 被误当作标准区间额度。
- xAI 周额度在上游未提供 `creditUsagePercent` 时继续保持“未知”。
- 大型 Codex 历史库的旧身份验证继续使用紧凑的派生 identity evidence。

## Upgrade Notes

- 这是一个标记为 `v7.2.151-max.3` 的 fork 预发布版本。
- 它仅用于发布当前 fork 镜像，没有额外迁移。
