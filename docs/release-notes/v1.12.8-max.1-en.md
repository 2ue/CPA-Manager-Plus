# CPA Manager Plus v1.12.8-max.1

> Fork prerelease based on v1.12.8

> [中文 ->](https://github.com/2ue/CPA-Manager-Plus/blob/v1.12.8-max.1/docs/release-notes/v1.12.8-max.1-zh.md)

## Overview

v1.12.8-max.1 is the first `max` prerelease for this fork. It centers on per-credential concurrency and RPM limits, cache final-value controls, and clearer usage visualization in request monitoring. The release keeps the existing account and scheduling model, but moves the most frequently used controls closer to accounts and configuration so they are easier to apply directly or in bulk.

## Highlights

### Features

- Account details can now set concurrency and RPM per credential, and the account list can batch-apply the same limits.
- Cache control now applies independently to read, write, input, and output paths, with threshold clipping, multipliers, and jitter ranges.
- Usage display in request monitoring is denser, so input, output, and cache dimensions are easier to compare at a glance.

### Fixes

- Claude-related configuration and account actions have been consolidated so common controls are no longer scattered across duplicated locations.
- The release path now matches the fork repository's `max` tag naming and release-content validation.

## Upgrade Notes

- This is a fork prerelease and uses the `v1.12.8-max.1` tag.
- Existing account data and historical monitoring data are unchanged; the new concurrency, RPM, and cache controls only affect future requests.
