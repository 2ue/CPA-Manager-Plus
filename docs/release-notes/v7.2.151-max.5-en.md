# CPA Manager Plus v7.2.151-max.5

> Fork prerelease based on v1.12.12

> [Chinese ->](https://github.com/2ue/CPA-Manager-Plus/blob/v7.2.151-max.5/docs/release-notes/v7.2.151-max.5-zh.md)

## Overview

v7.2.151-max.5 teaches credential import about Claude Code accounts. A sub2api export previously yielded only OpenAI OAuth accounts, silently dropping any Anthropic account it carried. Both platforms are now converted, including exports that mix the two.

Claude accounts in the CPA format already imported and are unaffected.

## Highlights

### Features

- Anthropic OAuth accounts in a sub2api export convert into CPA-compatible Claude login files.
- An export holding both OpenAI and Anthropic accounts converts both into separate files instead of keeping only the OpenAI ones.
- Imported Claude files are named `claude-<email>.json`. When one email holds several organizations, the organization identifier is added to keep them distinct.
- Unsupported platforms and non-OAuth account types are skipped rather than failing the whole import.

### Fixes

- sub2api serialises `expires_at` as an absolute Unix-seconds string, which is now converted to the RFC3339 value CPA expects.

## Upgrade Notes

- This is a fork prerelease tagged `v7.2.151-max.5` and requires no manual migration.
- Behaviour change: a sub2api export previously imported only its OpenAI accounts, and now imports Anthropic accounts as well. Review the accounts list after importing if you relied on the previous behaviour.
