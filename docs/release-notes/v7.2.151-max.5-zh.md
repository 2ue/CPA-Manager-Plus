# CPA Manager Plus v7.2.151-max.5

> Fork prerelease based on v1.12.12

> [English ->](https://github.com/2ue/CPA-Manager-Plus/blob/v7.2.151-max.5/docs/release-notes/v7.2.151-max.5-en.md)

## Overview

v7.2.151-max.5 让凭证导入支持 Claude Code 账号。此前 sub2api 导出只会提取 OpenAI OAuth 账号，导出里的 Anthropic 账号会被静默丢弃；现在两种平台都会转换，混在同一份导出里也可以。

CPA 格式的 Claude 账号此前已可导入，本次不受影响。

## Highlights

### Features

- sub2api 导出中的 Anthropic OAuth 账号会转换成 CPA 可用的 Claude 登录文件。
- 一份导出里同时包含 OpenAI 与 Anthropic 账号时，两种都会转换并各自生成独立文件，不再只取 OpenAI。
- 导入生成的 Claude 文件按邮箱命名为 `claude-<email>.json`；同一邮箱下存在多个组织时，会自动补上组织标识以区分。
- 不支持的平台与非 OAuth 类型的账号会被跳过，不会导致整次导入失败。

### Fixes

- sub2api 的 `expires_at` 是绝对 Unix 秒的字符串，导入时会正确转换成 CPA 所需的 RFC3339 时间。

## Upgrade Notes

- 这是一个标记为 `v7.2.151-max.5` 的 fork 预发布版本，无需手动迁移。
- 行为变更：此前 sub2api 导出只会导入 OpenAI 账号，现在 Anthropic 账号也会一并导入。如果此前依赖"只导入 OpenAI"的行为，导入后请确认凭证列表。
